# Manuscript-facing evidence

This directory organizes potential research claims; it is not a submitted paper,
accepted publication or new performance result.

The current defensible account is an experimental study of flight disruption,
airport-network context and forecast-information timing. It includes controlled
historical comparisons, negative architectural results, a network-coverage audit,
a cutoff-validity correction and source-feasibility findings. Strict corrected
T−24 performance is not established.

- [Claim-to-evidence crosswalk](CLAIM_EVIDENCE_CROSSWALK.md): statements, sources and limits.
- [Result lineage](../docs/RESULT_LINEAGE.md): stages and non-comparable cohorts.
- [Current results](../docs/CURRENT_RESULTS.md): same-flight scores and uncertainty.
- [Experiment index](../docs/EXPERIMENT_INDEX.md): all retained experiment records.
- [Research roadmap](../docs/RESEARCH_ROADMAP.md): conditional next work.
- [Release checklist](../docs/RELEASE_CHECKLIST.md): exact-payload review before publication.

A software/audit/negative-results archive can have a narrower scope than a validated
forecast benchmark. It still needs accurate provenance, redistribution review and
owner approval; a Git repository or draft citation does not constitute peer review.
